# End-to-End A/B Testing & Causal Inference Platform

This project implements a Python-based experimentation engine for analyzing A/B tests and estimating treatment effects.

It simulates randomized experiments, calculates business metrics, and performs statistical hypothesis testing.

## Features

- Synthetic experiment data generation
- Conversion rate analysis
- Revenue comparison
- Lift calculation
- Hypothesis testing (z-test & t-test)
- Experiment summary output

## Tech Stack

Python  
Pandas  
NumPy  
SciPy  
Statsmodels
