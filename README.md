## 📖 About

This project implements a Python-based experimentation engine for analyzing A/B tests and estimating treatment effects. It simulates randomized experiments, calculates business metrics, and performs statistical hypothesis testing.

---

## ✨ Features

- 🎲 Synthetic experiment data generation
- 📊 Conversion rate analysis
- 💰 Revenue comparison
- 📈 Lift calculation
- 🧪 Hypothesis testing (z-test & t-test)
- 🖥️ Experiment summary output

## 🚀 Quickstart

```bash
# 1. Clone the repo
git clone https://github.com/yourusername/ab-testing-causal-platform.git
cd ab-testing-causal-platform

# 2. Install dependencies
pip install -r requirements.txt

# 3. Generate synthetic data
python src/generate_data.py

# 4. Run the experiment pipeline
python src/main.py
```
